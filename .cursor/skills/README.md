# Cursor skills in this repository

These are **workflow and quality guardrails**, not the implementation of MiniPay itself.

| Skill | Kind | When to use |
|---|---|---|
| `minipay-conventions` | Guardrail | Generating or editing API, UI, config, or logging |
| `incident-rca` | Guardrail | Drafting or structuring incident write-ups |
| `repo-hygiene` | Script-backed | Before push / PR: secrets, ignore rules, required files |

Git (commits, PRs, tags, merges) is owned by the human. Skills must not commit or open pull requests.

`scope-creep-detector` (optional, adopted from [awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps), Apache-2.0) may be installed locally to check a diff against stated intent. It is not vendored here.
